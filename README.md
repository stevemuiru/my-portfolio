# My Portfolio

A personal portfolio website built with React to showcase my projects and skills as an aspiring full stack engineer.

**Live Demo:** _add your deployed URL here_

## Overview

A single-page, responsive portfolio site featuring a fixed navigation bar, hero introduction, about section, tech stack showcase, project gallery, and contact links — all styled with a dark, techy theme.

## Tech Stack

- **React** (via Vite)
- **React Bootstrap** — responsive navbar and project cards
- **Bootstrap 5** — grid layout and utility classes
- **react-icons** — tech stack and contact icons

## Features

- 🌙 Dark, techy visual theme
- 📱 Fully responsive layout (mobile, tablet, desktop)
- 🧭 Fixed nav bar with smooth anchor-link scrolling to Home, About, and Contact
- 💼 Project showcase with live demo and GitHub links for each project
- 🛠️ Tech stack section with icons for each skill
- 📬 Direct contact links (email, phone, GitHub)

## Sections

| Section | Description |
|---|---|
| Hero | Name, role, and a short introduction with CTA buttons |
| About | Background and journey as a self-taught developer |
| Skills | Tech stack icons — HTML, CSS, JavaScript, React, Bootstrap, Node.js, PostgreSQL |
| Projects | Featured projects with descriptions, tech used, and links |
| Contact | Email, phone, and GitHub links |

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/stevemuiru/my-portfolio.git
cd my-portfolio
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.
